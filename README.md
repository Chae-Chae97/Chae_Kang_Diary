# 📖 My Diary (나만의 일기장 프로젝트)

> 소중한 하루의 기록을 담는 나만의 일기장 웹 서비스입니다.

## 🛠️ Tech Stack
- **Frontend**: Next.js (App Router), React, Tailwind CSS
- **Backend**: 
- **Cooperation**: GitHub Projects, Discord

## ✨ Key Features
- **일기 목록 및 달력**: 작성한 일기들을 달력과 리스트로 확인 및 검색/필터링
- **일기 작성 및 수정**: 감정 이모지와 함께 오늘의 기록 저장
- **통계 대시보드**: 감정 분포 및 최근 기분 추이 시각화
- **회원가입 및 로그인**: JWT 기반 보안 인증 및 개인 프로필 관리
- **다국어 지원**: 한국어, 영어, 일본어 선택 가능
- **테마 모드**: 라이트 모드 및 다크 모드 지원

## 🚀 How to Run (로컬 실행 방법)

1. 저장소를 클론합니다.
\`\`\`bash
git clone https://github.com/본인계정/Chae_Kang_Diary.git
\`\`\`

2. Frontend 폴더(client)로 이동하여 패키지를 설치합니다.
\`\`\`bash
cd client
npm install
\`\`\`

3. 개발 서버를 실행합니다.
\`\`\`bash
npm run dev
\`\`\`
- 브라우저에서 `http://localhost:3000`으로 접속하여 확인합니다.
